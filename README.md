# Student Grade Manager — Java

This mini app works as a grading system

## Features

- Add student — Adds Students to a list of students
- Remove student — Removes a Student from the list
- Search student — Checks if the student is in the list
- Print all students — Prints all the Students and their grades
- Class average — Gets the average of the whole class
- Top student — Finds the student with the highest average grade
- Bottom student — Finds the student with the lowest average grade

## What I learned

I practiced the thing that matters in the end which is combining concepts and using different classes into something that works and serves a purpose
